# QKD Security Lab

## Overview

QKD Security Lab is a self-directed educational research project exploring the foundations, implementation, and security analysis of Quantum Key Distribution (QKD).

The project begins with the quantum-mechanical principles underlying QKD and progresses toward implementation and security analysis of the BB84 protocol, including eavesdropping, Quantum Bit Error Rate (QBER), privacy amplification, and the relationship between QKD and existing cryptographic trust infrastructures.

The project is designed to build practical and theoretical foundations for further research in quantum-safe cryptography and cryptographic protocol security.

## Objectives

The main objectives are to:

- Understand the quantum principles underlying QKD.
- Implement an educational simulation of the BB84 protocol.
- Model an intercept-resend eavesdropping attack.
- Investigate how eavesdropping affects QBER.
- Study security assumptions and adversary models for QKD.
- Explore error correction and privacy amplification.
- Examine the relationship between QKD, PKI, and authentication.
- Explore how QKD and post-quantum cryptography can coexist in quantum-safe infrastructures.

## Scope and Limitations

This repository is an educational research project.

The implementations and simulations developed here are intended to demonstrate concepts and support learning. They should not be interpreted as production-ready QKD implementations or as formal security proofs of complete QKD protocols.
